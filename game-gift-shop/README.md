## 🚀 نحوه اجرا

### روش 1: باز کردن مستقیم
فایل `index.html` را در مرورگر خود باز کنید:
```bash
cd game-gift-shop
# سپس فایل index.html را دابل کلیک کنید
```

### روش 2: استفاده از Live Server (توصیه می‌شود)
اگر VS Code دارید:
1. افزونه Live Server را نصب کنید
2. روی `index.html` کلیک راست کنید
3. گزینه "Open with Live Server" را انتخاب کنید

### روش 3: استفاده از Python Server
```bash
cd game-gift-shop
python -m http.server 8000
# سپس به آدرس http://localhost:8000 بروید
```

### روش 4: استفاده از Node.js
```bash
cd game-gift-shop
npx http-server
```

## 🔧 سفارشی‌سازی

### تغییر رنگ‌ها
رنگ‌ها را در فایل `css/style.css` در بخش `:root` ویرایش کنید:
```css
:root {
    --primary-gold: #FFD700;
    --secondary-gold: #FFA500;
    /* ... */
}
```

### اضافه کردن محصول جدید
یک کپی از `.product-card` در فایل HTML بگیرید و اطلاعات را تغییر دهید:
```html
<div class="product-card glass-card">
    <!-- محتوای محصول -->
</div>
```

### تغییر محتوای متنی
تمامی متن‌ها در فایل `index.html` قابل ویرایش هستند.
